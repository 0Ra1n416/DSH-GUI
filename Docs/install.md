# DSH-GUI 安装与使用指南

本文档面向**使用安装包的用户**（开发者请移步 [README](../README.md) 与 [build.md](build.md)）。

## 安装前要求（两平台一致）

| 组件 | 必需性 | 用途 |
|---|---|---|
| Node.js + npm | **必需** | 应用通过 `npx` 启动 DeepSeek Harness 后端 |
| pnpm | 可选 | 插件管理器的"安装/卸载插件"功能 |
| 网络 | 首次需要 | 首次启动或预载 dsh 时下载 |

## Windows

### 安装步骤

1. 双击 `DSH-GUI-Setup-<版本>.exe`
2. **欢迎 → 选择安装目录**（默认 `%LOCALAPPDATA%\Programs\DSH-GUI`）
3. **端口设置**：输入后端监听端口（`0` = 系统随机分配；范围 0-65535）。勾选"安装前检查环境"则进入环境检查页，不勾选则跳过（有提示：缺少 Node.js/npm/pnpm 时应用可能无法正常运行）
4. **环境检查**（勾选后出现）：逐项执行 `node --version` / `npm --version` / `pnpm --version` 并实时显示结果——
   - 缺 node/npm：点"前往官网下载 Node.js"，**安装完成后关闭并重新打开安装程序**再继续
   - 仅缺 pnpm：点"自动安装 pnpm"（装完自动复检）
   - 也可点"跳过"（弹风险提示，确认后继续）
5. **预载 DeepSeek Harness**（环境检查全部通过后出现）：点"开始预载"会在独立控制台窗口提前下载 dsh（进度可见），加快第一次启动；也可直接下一步跳过
6. **安装 → 完成**

端口写入 `<安装目录>\Config\config.json`，安装后随时可改。

### 卸载

Windows"设置 → 应用"或开始菜单的卸载入口；卸载会移除安装目录（含其中的配置）。

## Linux

### 安装

| 产物 | 方式 |
|---|---|
| AppImage | `chmod +x DSH-GUI-*.AppImage` 后直接运行 |
| deb | `sudo apt install ./dsh-gui_<版本>.deb`（或 `dpkg -i`） |

Linux 版没有安装向导：端口首次用默认值（或随机），进入应用后用托盘"系统设置"修改。

### 卸载

- AppImage：直接删除文件即可
- deb：`sudo apt remove dsh-gui`

## 配置

配置文件位置因平台而异，改法一致（托盘"系统设置"窗口保存即生效，或手改文件后重启后端）：

| 平台 | 配置位置 |
|---|---|
| Windows | `<安装目录>\Config\config.json` |
| Linux | `~/.config/DSH-GUI/config.json` |

```json
{
  "host": "127.0.0.1",
  "port": 3080
}
```

- 端口被占用或系统保留（EACCES）时，应用会弹窗提示，点"重启（端口设为 0）"自动改用随机端口
- Windows 上若把程序装进需要管理员权限的目录（如 `C:\Program Files`），写配置可能失败，此时应用回退默认值并记录日志

## 日常使用（两平台一致）

- 首次启动会看到启动动画，后端就绪后自动进入 DSH 界面
- 点击窗口关闭按钮会**最小化到系统托盘**（后端继续运行）；完全退出请用托盘菜单"退出 DeepSeek Harness"
- 托盘菜单：
  - **显示主窗口** —— 从托盘恢复窗口
  - **插件管理** —— 安装/启停/卸载 DSH 插件（npm 包、本地目录、Git 仓库）
  - **系统设置** —— 修改 host/port，保存后自动重启后端
  - **重启后端** —— 手动重启（改配置或插件后可用，重启完成后主窗口自动刷新）
  - **打开日志文件夹** —— 查看运行日志（`%APPDATA%\DSH-GUI\logs` / `~/.config/DSH-GUI/logs`）
  - **开机自启** —— 仅 Windows；勾选后随 Windows 启动

## 插件

在"插件管理"窗口安装，三种来源：

| 来源 | 说明 |
|---|---|
| npm 包 | 输入包名，如 `@scope/dsh-plugin-demo` |
| 本地目录 | 选择目录；"链接安装"（开发模式，改代码即生效）或"复制安装" |
| Git 仓库 | `github:user/repo`、`git+https://…` 等形式 |

安装/启停后需点击"重启后端"生效（应用会自动刷新主窗口）。pnpm 构建脚本审批（如 `ssh2`）会自动处理。

## 常见问题

- **双击启动后没有窗口**：多半缺少 Node.js/npm。看日志（路径见上表）；Windows 上重装时勾选环境检查可提前发现
- **弹窗"端口绑定失败（EACCES）"**：端口被系统保留（Windows 常见于 Hyper-V/WSL 保留段）。点"重启（端口设为 0）"改用随机端口，或改配置文件换端口
- **第一次启动很慢**：正在下载 dsh，属正常；Windows 安装时用"预载"可提前完成
- **窗口只剩托盘图标**：关闭按钮是"最小化到托盘"，用托盘菜单恢复或退出
